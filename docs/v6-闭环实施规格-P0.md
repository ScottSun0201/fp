## §1 P0 目标（唯一主线）

> **把每一笔"对不上"变成一张"差异工单"**：有状态、有负责人、有处理动作、有结果；跨月跟踪；处理不完的差异必须带说明才能核销。

P0 交付后，任意一笔差异都能回答 6 个问题（v4 §6 验收清单）：
谁发现的 / 谁负责 / 什么原因 / 怎么处理的 / 留痕吗 / 下月还看得见吗

## §2 P0 拆成 5 个功能点（按依赖排序）

### F1 · 差异工单生成（基础）
- **触发点**：对账单逐行校验环节，凡是"校验不通过 / 超额 / 需人工确认"的行，**自动生成一张差异工单**
- **工单自带信息**：所属对账任务、行号、供应商/客户、金额、差异原因分类（5 类）、差异金额、生成时间
- **不重复生成**：同一对账任务、同一行，只允许一张在"未关闭"状态的工单
- **验收**：上传一张有差异的对账单 → 差异清单页能看到对应工单，每单有唯一编号

### F2 · 差异清单页（工单视图）
- **入口**：现有"逐行处理"页升级为"差异清单"，默认只显示有问题的行
- **列表字段**：工单号 / 供应商 / 行号 / 差异金额 / 原因分类 / 状态 / 负责人 / 处理时间
- **筛选**：按状态、按供应商、按对账任务、按月份
- **验收**：财务打开页面，一眼看到"本月还有多少差异没处理完、都是谁、卡在哪"

### F3 · 工单状态机（流转规则）
```
待处理 ──认领──▶ 处理中 ──处理完成──▶ 已解决
   │                  │
   │ 标遗留(必填原因)  │ 标遗留(必填原因)
   ▼                  ▼
 遗留 ──▶ 下月自动带入，重新变为"待处理"（保留原工单号+历史记录）
```
- 状态只能按箭头流转，不能跳步、不能回退到更早状态
- 任何状态变化记录：谁、何时、从什么到什么、备注
- **验收**：操作一遍全流程，状态变化与记录完整可查

### F4 · 核销校验（防带病核销）
- 点击"确认对账"时检查：该任务是否存在**非"已解决"**的差异工单
- 存在 → 弹窗要求勾选"差异处理说明"（列出遗留工单 + 填写原因）→ 才允许核销
- 核销记录里**永久保存这份说明**，可追溯
- **验收**：故意留一张差异工单不处理 → 点确认对账 → 被拦截 → 填说明后通过 → 核销记录里能看到说明

### F5 · 跨月带入（月度滚动闭环）
- 每月对账开始时（新建对账任务时），系统自动把上月**状态为"遗留"**的工单带入本月任务
- 带入规则：保留原工单号、原差异、原处理记录；状态重置为"待处理"；标记"本月带入"
- 本月差异清单 = 上月遗留（带入）+ 本月新增
- **验收**：上月遗留 3 笔 → 新建本月对账 → 差异清单出现这 3 笔且标注"带入"，历史记录完整

## §4 P0 验收标准（总）

1. 上传对账单 → 差异自动成单，清单页可查可筛
2. 工单全流程可走：认领→处理→已解决 / 遗留（必填原因）
3. 有差异未处理完 → 核销被拦截，填说明后放行且留痕
4. 上月遗留 → 本月自动带入，历史可追
5. 全程操作留痕（谁、何时、做了什么）
